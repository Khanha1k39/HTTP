🔀
Multiplexing

HTTP/2 gửi nhiều request song song trên 1 TCP connection. HTTP/1.1 bị giới hạn 6 connections mỗi domain.

🗜️
Header Compression (HPACK)

HTTP/2 nén headers bằng HPACK, giảm 85-95% kích thước header so với HTTP/1.1 plain text.

⚙️
Binary Protocol

HTTP/2 dùng binary framing thay vì text, giúp parse nhanh hơn và ít lỗi hơn.

🚦
Head-of-Line Blocking

HTTP/1.1 bị HOL blocking: request sau phải chờ request trước hoàn thành trên cùng connection.

📡
Server Push

HTTP/2 cho phép server chủ động gửi tài nguyên trước khi client request (Server Push).

🔒
HTTPS Required

Trên thực tế, HTTP/2 yêu cầu TLS trên hầu hết browser. HTTP/1.1 vẫn hoạt động qua HTTP thường.
